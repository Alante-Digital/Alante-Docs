## Flujo típico

```mermaid
flowchart LR
  A[Canal: email / web / WhatsApp] --> B[Ticket]
  B --> C[Asignación / SLA]
  C --> D[Respuesta]
  D --> E[Cierre / encuesta]
```

<Tip>
  Define etiquetas, prioridades y SLAs **antes** de abrir el canal al público. Documenta en la base de conocimientos lo que más se repite.
</Tip>
