## Información general

1. Configuración → **Generales**
2. Completa razón social, RNC y datos de contacto
3. Guarda

## Branding (identidad visual)

1. **Branding → Nuevo branding**
2. Nombre interno y de marca, colores, logo (JPG/PNG/GIF, máx. 2 MB)
3. Email, teléfono, sitio web y dirección
4. Puedes tener varias marcas y elegir la principal en documentos

## Facturación y cotizaciones

- Pie de página de facturas y cotizaciones
- Series y comportamientos por defecto de documentos de venta

## Clientes

- Campos **personalizados** en la ficha (zona, vendedor asignado, etc.)

## Productos / Inventario

- Unidades por defecto, comportamiento de código de barras en productos pesados, etc.

## Punto de venta (POS)

- Pie de tickets y cantidad de copias
- Correos para **resumen de cierre** de sesión
- **Permitir que el cajero vea el efectivo esperado** (arqueo ciego vs supervisado)

Detalle de operación: [Punto de venta](/punto-de-venta/tablero).

## Fiscal y e-CF

- Indica si operas bajo **RST**
- Certificación y certificado en [Facturación electrónica](/introduccion/facturacion-electronica)
- Lotes de NCF en [Fiscal → Autorizaciones](/fiscal/autorizaciones)

## Integraciones

### Link de Pago Azul Dominicana

1. **Integraciones → Link de Pago Azul**
2. Activa el botón en facturas públicas
3. Merchant ID, Private Key, moneda y [pasarela](/cajas-y-bancos/pasarelas-de-pago)
4. (Opcional) email de pagos aprobados

Flujo del cliente: [Facturación](/ventas/facturacion).

### Claves de API

Crea claves para conectar Alante con otros sistemas. Documentación: [API de facturación electrónica](/api-facturacion-electronica).

<Warning>
  Copia la API Key en el momento de crearla: suele mostrarse **una sola vez**.
</Warning>
